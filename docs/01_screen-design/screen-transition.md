# 画面遷移図（Week 21 確定版）

> [要件定義書 7章](../requirements.md#7-画面遷移図)の内容を清書したもの。Figma の「03_Flow」ページはこの図をもとに描く。
> 画面ID（S-xx）は要件定義書 7.1、URL は [ルーティング設計](../03_routing/routes.md) と対応している。
> 今回（Week 22〜24）作る画面だけを描いている。

## 凡例

| 表記 | 意味 |
|------|------|
| 四角 | 自サイトの画面 |
| 実線 | 画面を移動する |
| 点線 | 条件によって移動する |
| （Ajax） | ページを再読み込みせず、同じ画面の中で表示が変わる |

サイト全体がログイン必須（F-29）。会員登録（S-14）とログイン（S-15）以外の画面は、ログインしないと開けない。

## 1. ログインまでの流れ

```mermaid
flowchart TD
    ANY["サイトのどのURLを開いても<br>（未ログイン）"] --> LOGIN["S-15 ログイン<br>チーム紹介文"]
    LOGIN -->|会員登録する| REG["S-14 会員登録"]
    REG -->|登録完了（ファンとして登録）| TOP["S-01 トップ"]
    LOGIN -->|ログイン| BACK{"開こうとしていた<br>画面がある？"}
    BACK -->|ある| ORIG["その画面"]
    BACK -->|ない| TOP
    LOGIN -.->|パスワードを忘れた| RESET["パスワード再設定<br>（Breeze 標準）"]
```

- ログイン後は、もともと開こうとしていた画面へ戻る。ログイン画面を直接開いた場合はトップへ
- ヘッダーの [ログアウト] を押すと、どの画面からでも S-15 に戻る

## 2. 全体（会員のファン・ダンサー共通）

どの画面からも、ヘッダーメニュー（トップ・メンバー・スケジュール・ブログ・お問い合わせ・ログアウト）で主要ページへ1クリックで移動できる（NF-14）。図が複雑になるため、ヘッダーからの矢印はトップからの矢印で代表させている。

```mermaid
flowchart TD
    TOP["S-01 トップ<br>NEXT STAGE・チーム紹介"]

    subgraph info["チーム情報"]
        MEM["S-03 メンバー一覧"]
        SCH["S-05 出演スケジュール一覧"] --> SCHD["S-06 出演スケジュール詳細"]
    end

    subgraph contact["お問い合わせ"]
        CON["S-11 入力"] -->|送信する| CONF["S-13 送信完了"]
        CONF -->|トップへ戻る| TOP2["S-01 トップ"]
    end

    subgraph blog["ブログ"]
        BLOG["S-19 ブログ一覧"] --> BLOGD["S-20 ブログ詳細"]
    end

    TOP --> MEM & SCH & CON & BLOG
    TOP -.->|NEXT STAGE の公演| SCHD
    MEM -.->|ブログを見る（そのメンバーで絞り込み）| BLOG
    TOP -->|ログアウト| LOGIN["S-15 ログイン"]
```

- お問い合わせは確認画面（S-12・Should）を作らず、入力から直接送信する
- S-13 は送信後にリダイレクトで表示する。送信せずにURLを直接開いた場合は S-11 へ戻す

## 3. ブログ（会員のファン）

```mermaid
flowchart TD
    BLOG["S-19 ブログ一覧"] -->|メンバーで絞り込み| BLOG
    BLOG -->|ページ送り（絞り込み条件は保持）| BLOG
    BLOG -->|記事を押す| BLOGD["S-20 ブログ詳細"]
    BLOGD -->|いいね・取り消し（Ajax）| BLOGD
    BLOGD -->|書いた人の名前・記事一覧を見る| BLOGM["S-19 ブログ一覧<br>（そのメンバーで絞り込み）"]
    BLOGD -->|ブログ一覧に戻る| BLOG
```

## 4. ブログ（ダンサー）

ダンサーは、会員のファンと同じ画面に加えて、ブログの投稿・編集・削除ができる。

```mermaid
flowchart TD
    BLOG["S-19 ブログ一覧"] -->|投稿する（ダンサーのみ表示）| NEW["S-22 ブログ投稿"]
    NEW -->|保存する| BLOGD["S-20 ブログ詳細<br>「投稿しました」"]
    NEW -->|キャンセル| BLOG

    BLOGD -->|編集する（本人のみ表示）| EDIT["S-22 ブログ編集"]
    EDIT -->|保存する| BLOGD2["S-20 ブログ詳細<br>「更新しました」"]
    EDIT -->|キャンセル| BLOGD

    BLOGD -->|削除する（本人のみ表示・確認ダイアログ）| BLOG2["S-19 ブログ一覧"]

    FAN["ファンが S-22 のURLを直接開く"] -.-> E403["403 エラー"]
    OTHER["他人の記事の編集URLを直接開く"] -.-> E403
```

- 投稿できるのはダンサーのみ（PostPolicy の create）、編集・削除は書いた本人のみ（PostPolicy の update・delete）
- 権限がない人には、[投稿する] [編集する] [削除する] のボタンを表示しない（NF-22）
