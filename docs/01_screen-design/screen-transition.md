# 画面遷移図

> [要件定義書 5章](../requirements.md#5-画面遷移図)の簡易版を清書したもの。Figma の「03_Flow」ページはこの図をもとに描く。
> 画面ID（S-xx）は要件定義書 5.1、URL は [ルーティング設計](../03_routing/routes.md) と対応している。

## 凡例

| 表記 | 意味 |
|------|------|
| 四角 | 自サイトの画面 |
| 六角形 | 外部サービス（Stripe） |
| 🔒 | ログインが必要（未ログインならログイン画面へ。ログイン後は元の画面に戻る） |
| 点線 | 条件によって移動する |

## 1. 全体（ファン向け）

どの画面からも、ヘッダーメニューで主要ページへ1クリックで移動できる（NF-14）。図が複雑になるため、ヘッダーからの矢印はトップからの矢印で代表させている。

```mermaid
flowchart TD
    TOP["S-01 トップ"]

    subgraph info["チーム情報（誰でも見られる）"]
        TEAM["S-02 チーム紹介"]
        MEM["S-03 メンバー一覧"] --> MEMD["S-04 メンバー詳細"]
        SCH["S-05 出演スケジュール<br>カレンダー"] --> SCHD["S-06 出演スケジュール詳細"]
        MOV["S-07 ダンス動画一覧"]
    end

    subgraph goods["グッズ（誰でも買える）"]
        GDS["S-08 グッズ一覧"] --> GDSD["S-09 グッズ詳細"]
    end

    subgraph contact["お問い合わせ"]
        CON["S-11 入力"] -->|確認する| CONC["S-12 確認"]
        CONC -->|修正する| CON
        CONC -->|送信する| CONF["S-13 送信完了"]
    end

    subgraph member["会員限定 🔒"]
        MY["S-17 マイページ"]
        OMI["S-18 おみくじ"]
        BLOG["S-19 ブログ一覧"] --> BLOGD["S-20 ブログ詳細"]
    end

    TOP --> TEAM & MEM & SCH & MOV & GDS & CON
    TOP --> MY & OMI & BLOG
    TOP --> REG["S-14 会員登録"] --> MY
    TOP --> LOGIN["S-15 ログイン"]
    LOGIN -->|ファン| MY
    MEMD -.->|このメンバーのブログ| BLOG
    TOP -.->|直近の出演予定| SCHD
    TOP -.->|新着グッズ| GDSD
```

## 2. 購入の流れ

```mermaid
flowchart TD
    GDSD["S-09 グッズ詳細"] -->|購入する| STRIPE1{{"Stripe 決済画面<br>配送先・メール入力"}}
    GDSD -.->|在庫0| SOLD1["SOLD OUT（押せない）"]
    STRIPE1 -->|決済完了| DONE["S-10 購入完了<br>注文番号を表示・完了メール送信"]
    STRIPE1 -->|戻る| GDSD

    SCHD["S-06 出演スケジュール詳細"] -->|ログイン済み| TCK["S-16 チケット購入確認<br>1人2枚まで"]
    SCHD -->|未ログイン| LOGIN["S-15 ログイン"] -->|元の画面に戻る| SCHD
    SCHD -.->|残り0枚・購入上限| SOLD2["購入ボタンを押せない"]
    TCK -->|決済に進む| STRIPE2{{"Stripe 決済画面"}}
    STRIPE2 -->|決済完了| DONE
    STRIPE2 -->|戻る| TCK
    DONE -->|チケットのとき| MY["S-17 マイページ<br>電子チケット"]
    DONE -->|グッズのとき| TOP["S-01 トップ"]
```

## 3. おみくじ・ブログ（会員）

```mermaid
flowchart TD
    OMI["S-18 おみくじ"] -->|引く（Ajax・画面移動なし）| OMIR["同じ画面に結果を表示"]
    OMI -.->|今日すでに引いた| OMIR
    BLOG["S-19 ブログ一覧"] --> BLOGD["S-20 ブログ詳細"]
    BLOGD -->|いいね（Ajax・画面移動なし）| BLOGD
```

## 4. ダンサー向け

```mermaid
flowchart TD
    LOGIN["S-15 ログイン"] -->|ダンサー| MINE["S-21 自分の投稿一覧<br>いいね数"]
    MINE -->|新規投稿| EDIT["S-22 ブログ投稿・編集"]
    MINE -->|編集| EDIT
    EDIT -->|保存| MINE
    EDIT -->|キャンセル| MINE
    MINE -->|削除（確認ダイアログ）| MINE
    MINE -->|タイトル| BLOGD["S-20 ブログ詳細"]
```

ダンサーも会員と同じくファン向け画面（ブログ一覧・おみくじなど）を見られる。ヘッダーに「自分の投稿」が増える。

## 5. 管理者向け

```mermaid
flowchart TD
    LOGIN["S-15 ログイン"] -->|管理者| DASH["S-23 管理ダッシュボード"]
    DASH --> A1["S-24 出演スケジュール管理<br>（チケット価格・販売枚数も設定）"]
    DASH --> A2["S-25 商品管理"]
    DASH --> A3["S-26 メンバー管理"]
    DASH --> A4["S-27 動画管理"]
    DASH --> A5["S-28 お問い合わせ一覧"]
    DASH --> A6["S-29 注文一覧"]
    A1 --> A1F["登録・編集フォーム"] -->|保存| A1
    A2 --> A2F["登録・編集フォーム"] -->|保存| A2
    A3 --> A3F["登録・編集フォーム"] -->|保存| A3
    A5 --> A5D["お問い合わせ詳細<br>対応済みにする"]
    A6 --> A6D["注文詳細<br>配送先"]
```

管理画面の登録・編集フォームは、要件定義書の画面一覧では各管理画面（S-24〜S-29）に含めている。ルーティング設計では別のURL（`/create`・`/{id}/edit`）になる。
