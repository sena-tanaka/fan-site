> Figma で描く前の下書き。スマホ幅（375px）を基準にしている（NF-12）。
> Figma の URL は [figma.md](./figma.md)、画面遷移は [screen-transition.md](./screen-transition.md) を参照。
> 画面IDは[要件定義書 7.1](../requirements.md#71-画面一覧)と同じ。URLは[ルーティング設計](../03_routing/routes.md)と対応する。
> S-14 会員登録は Breeze の標準画面をそのまま使うため、ここでは描かない。

## 共通パーツ

### ヘッダー（S-14・S-15 以外のすべての画面）

```
┌───────────────────────────────┐
│ [ロゴ] BEAT CREW          [≡] │ ← ≡ でメニューを開く
└───────────────────────────────┘
 メニュー（開いたとき）
 ・トップ ・メンバー ・スケジュール
 ・ブログ ・お問い合わせ
 ──────────
 ○○ さん          [ログアウト]
```
- サイト全体がログイン必須なので、ヘッダーが出る画面では必ずログインしている（F-29）
- ファンとダンサーでメニューは同じ。ダンサーはブログ一覧（S-19）の [+ 投稿する] から記事を書く
- PC幅ではメニューを横並びで常に表示する（NF-14：主要ページへ1クリック）
- [ログアウト] を押すとログイン画面（S-15）へ

### フッター
- 各ページへのリンク、コピーライト

## 6. S-19 ブログ一覧（メンバーで絞り込み）

```
┌───────────────────────────────┐
│ ヘッダー                       │
├───────────────────────────────┤
│ BLOG              [+ 投稿する] │ ← ダンサーのみ表示 → S-22
│ [すべて][RYO][名前][名前][名前]→ │ ← 横スクロール
│ ───────────────               │
│ ┌───────────────────────────┐ │
│ │ ┌──────┐ タイトル           │ │
│ │ │画像  │ [アイコン] RYO      │ │
│ │ └──────┘ 2026/10/18   ♥ 24 │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │ ┌──────┐ タイトル           │ │
│ │ │画像  │ [アイコン] 名前     │ │
│ │ └──────┘ 2026/10/15   ♥ 8  │ │
│ └───────────────────────────┘ │
│ （10件ずつ）                     │
│      [<] 1 2 3 [>]             │
├───────────────────────────────┤
│ フッター                       │
└───────────────────────────────┘
```
| 要素 | 内容 | 対応 |
|------|------|------|
| 投稿するボタン | ダンサーにだけ表示する | F-19, NF-22 |
| メンバーで絞り込み | 押したメンバーの記事だけを表示する。選んでいるボタンは色を反転する | F-32, US-23 |
| 記事カード | 画像・タイトル・書いた人・投稿日・いいね数。押すと S-20 へ | F-17, US-10 |
| ページ送り | 10件ずつ（NF-04） | F-17 |

- 絞り込みは URL のクエリで行う（`GET /blog?member={id}`）。絞り込んだままページを送っても、条件が外れないようにする
- 新しい順に並べる
- 画像がない記事は、画像の場所に「NO IMAGE」の枠を表示する
- 記事がないときは「まだ投稿がありません」と表示する
- 一覧のいいね数は表示のみ。いいねは詳細（S-20）で押す
- 書いた人といいね数は Eager Loading でまとめて取得する（NF-03）

## 7. S-20 ブログ詳細（いいね）

```
┌───────────────────────────────┐
│ ヘッダー                       │
├───────────────────────────────┤
│ < ブログ一覧に戻る              │
│ [アイコン] RYO     2026/10/18   │ ← 名前を押すと S-19（RYOで絞り込み）へ
│ タイトル                        │
│ ┌───────────────────────────┐ │
│ │         画像               │ │
│ └───────────────────────────┘ │
│ 本文                            │
│ ……                             │
│ ┌──────────┐                   │
│ │ ♡ 24     │ ← 押すと ♥ 25 になる  │
│ └──────────┘                   │
│ ───────────────               │
│ [編集する] [削除する]             │ ← 書いた本人のみ表示
│ ───────────────               │
│ RYO の記事一覧を見る >            │ → S-19（RYOで絞り込み）
├───────────────────────────────┤
│ フッター                       │
└───────────────────────────────┘
```
| 要素 | 内容 | 対応 |
|------|------|------|
| いいね | ♡ を押すといいね、♥ を押すと取り消し。数もその場で変わる | F-18, US-11 |
| いいね数 | 書いた本人も含め、全員に表示する | US-15 |
| 編集・削除 | 書いた本人にだけ表示する | F-20, NF-22 |
| 記事一覧へのリンク | 同じメンバーで絞り込んだ一覧へ | F-32 |

- いいねは **Ajax（JSON）** で登録・取り消しする（`POST`・`DELETE /blog/{post}/like`）。ページは再読み込みしない
- リクエストには CSRF トークンを付ける（NF-07）
- 1記事につき1人1回（F-18）。押した後は ♥（塗りつぶし）になる
- 通信に失敗したときは表示を元に戻し、「通信に失敗しました」と表示する
- [削除する] は確認ダイアログを出し、削除後は S-19 へ移動する
- 画像がない記事は、画像の場所を表示しない

## 8. S-22 ブログ投稿・編集（ダンサー）

```
┌───────────────────────────────┐
│ ヘッダー                       │
├───────────────────────────────┤
│ ブログを書く（編集時：ブログを編集）  │
│ タイトル *                       │
│ [                             ] │
│ 画像                            │
│ ┌──────────┐                   │
│ │ 現在の画像 │ [画像を選ぶ]        │ ← 編集時だけ現在の画像を表示
│ └──────────┘ 選んだファイル名      │
│ ※jpg/png/webp・2MBまで           │
│ 本文 *                          │
│ ┌───────────────────────────┐ │
│ │                           │ │
│ │                           │ │
│ └───────────────────────────┘ │
│ [キャンセル]          [保存する]  │
├───────────────────────────────┤
│ フッター                       │
└───────────────────────────────┘
```
| 項目 | ルール | 対応 |
|------|--------|------|
| タイトル | 必須・100文字まで | F-19 |
| 画像 | 任意・jpg/png/webp・2MBまで・1枚 | F-19, NF-11 |
| 本文 | 必須・5000文字まで | F-19 |

- 画像はローカル（storage/app/public）に保存する（F-19、NF-17）
- 編集で新しい画像を選ぶと差し替える。古い画像のファイルは削除する
- 入力エラーは項目のすぐ下に赤字の日本語で表示し、入力した内容は残す（NF-15）
- [保存する] で S-20 へ移動し、「投稿しました」「更新しました」と表示する
- [キャンセル] は、新規なら S-19、編集なら S-20 に戻る
- 新規投稿はダンサーのみ（PostPolicy の create）。ファンがURLを直接開くと 403（NF-08）
- 編集は自分の投稿のみ（PostPolicy の update）。他人の投稿の編集URLを開くと 403（F-20）
- 下書き機能は作らない（保存するとすぐ公開）
