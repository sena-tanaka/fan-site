## 1. 見積もりの根拠

金額は **時間 × 単価 5,000円/h** で計算しています（単価は練習用に決めた仮の値）。

| 項目 | 時間 | 金額 | 内容 |
|------|-----:|-----:|------|
| 要件定義 | 6h | 30,000円 | [要件定義書](./requirements.md)（ヒアリング・ユーザーストーリー・機能要件・非機能要件） |
| 画面設計 | 8h | 40,000円 | [画面設計](./01_screen-design/)（Figma のワイヤーフレーム・画面遷移図） |
| DB設計 | 4h | 20,000円 | [DB設計書](./02_database/)（テーブル定義・ER図）、ルーティング・インフラ構成の設計を含む |
| フロントエンド開発 | 10h | 50,000円 | 共通レイアウト、チーム紹介・メンバー・出演予定・カレンダー・お問い合わせの画面 |
| バックエンド開発 | 13h | 65,000円 | 環境構築、マイグレーション・シーダー、各機能のルート・コントローラー・Service・Repository |
| テスト・デバッグ | 3h | 15,000円 | 各機能の Feature Test |
| **合計** | **44h** | **220,000円** | |

- 設計（要件定義・画面設計・DB設計）の時間は Week 18〜19 の作業の**仮の値**です。実際にかかった時間に Week 21 で置き換えます
- 開発（フロントエンド・バックエンド・テスト）の 26h は、[工数見積もり](./04_estimate/estimate.md)の「画面・処理・テスト」の列をそれぞれ足したものです
