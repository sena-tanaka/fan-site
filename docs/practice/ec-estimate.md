## 1. 見積もりの根拠

金額は **時間 × 単価 5,000円/h** で計算している（単価は練習用の仮の値）。

| 項目 | 時間 | 金額 | 内容 |
|------|-----:|-----:|------|
| 要件定義 | 8h | 40,000円 | ヒアリング・ユーザーストーリー・機能一覧の作成 |
| 画面設計 | 12h | 60,000円 | Figma のワイヤーフレーム（SP・PC）・画面遷移図（[画面設計](./ec-screen-design.md)） |
| DB設計 | 6h | 30,000円 | テーブル定義・ER図（商品・カテゴリ・カート・注文・会員・お気に入り・レビュー） |
| フロントエンド開発 | 30.5h | 152,500円 | 画面（Blade・CSS・JS）の作成 |
| バックエンド開発 | 39.5h | 197,500円 | 環境構築・DB・ルート・コントローラー・決済・在庫・デプロイ |
| テスト・デバッグ | 13h | 65,000円 | Feature Test（決済・在庫・権限を重点的に） |
| **合計** | **109h** | **545,000円** | |

- 設計（要件定義・画面設計・DB設計）の 26h は、開発の前に行う作業として見積もった
- 開発の 83h は、練習課題1の各タスクを「画面・処理・テスト」に分けて足したもの（下表）

## 2. 見積もりの範囲

| 含むもの | 含まないもの |
|----------|-------------|
| 上記の設計・開発・テスト | サーバー・ドメイン・Stripe の決済手数料などの利用料 |
| 本番環境（AWS）へのデプロイ | 商品写真の撮影・商品説明文の作成 |
| | 公開後の保守・運用（別途お見積もり） |
| | 商品の実際の発送業務 |

## 3. 前提条件

- 見積もりの有効期限は、見積日から30日とする
- 開発中に機能の追加・変更があった場合は、追加分を別途お見積もりする
- 決済は Stripe を使い、クレジットカード情報はサイトに保存しない
