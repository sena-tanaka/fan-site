# ユーザーストーリー（ECサイト機能）

> BEAT CREW 公式ファンサイトのうち、ECサイトにあたる「グッズ購入」「チケット購入」の機能を、
> ユーザーストーリーで詳しく記述したもの。
> 全体のユーザーストーリーは[要件定義書 2章](../requirements.md)を参照。

## 書き方
- 形式：【誰が】として、【何を】したい、なぜなら【なぜ】だから。
- **受け入れ条件**：そのストーリーが「完成した」と言える条件
- **関連**：要件定義書のユーザーストーリー（US）・機能（F）との対応

---

## 1. グッズ購入（未登録のファン・会員共通）

### EC-01 グッズを探す
【ファン】として、【グッズの一覧を見】たい、なぜなら【欲しいグッズを一目で探したい】から。

**受け入れ条件**
- グッズの画像・商品名・価格が一覧で表示される
- ログインしていなくても見られる
- 売り切れのグッズには「SOLD OUT」と表示される

**関連**：US-05 / F-11

### EC-02 グッズの詳細を確かめる
【ファン】として、【グッズの詳細を確認】したい、なぜなら【買う前にサイズや素材を確かめて、イメージと違うものを買いたくない】から。

**受け入れ条件**
- 画像・商品名・価格・説明文・在庫状況が表示される
- 在庫がある場合のみ「購入する」ボタンが押せる

**関連**：US-05 / F-11

### EC-03 会員登録なしで購入する
【未登録のファン】として、【会員登録をせずにグッズを購入】したい、なぜなら【公式のグッズを持って、応援をしたい】から。

**受け入れ条件**
- ログインしていなくても「購入する」ボタンから決済に進める
- 1回の購入は1個とする（複数個の購入はカート機能（EC-06）で対応）
- Stripeの決済画面でクレジットカード決済ができる
- 決済が完了すると、グッズの在庫が1つ減る
- 在庫が0のときは購入できない

**関連**：US-05 / F-12

### EC-04 配送先を入力する
【ファン】として、【購入時に配送先を入力】したい、なぜなら【購入したグッズを確実に自宅に届けてほしい】から。

**受け入れ条件**
- 決済画面で名前・住所・電話番号・メールアドレスを入力できる
- 必須項目が空のままでは購入できない

**関連**：US-05 / F-12

### EC-05 購入できたことを確認する
【ファン】として、【購入が完了したことを確認】したい、なぜなら【ちゃんと注文できたのか不安になりたくない】から。

**受け入れ条件**
- 決済完了後に購入完了画面が表示される
- 購入完了画面に注文番号・商品名・金額が表示される
- 入力したメールアドレスに購入完了メールが届く

**関連**：US-05 / F-12

### EC-06 まとめて購入する（任意）
【ファン】として、【複数のグッズをカートに入れてまとめて購入】したい、なぜなら【1回の支払いで欲しいグッズをすべて買いたい】から。

**受け入れ条件**
- グッズをカートに追加・削除できる
- カート内の合計金額が表示される
- カート内のグッズをまとめて決済できる

**関連**：US-05 / F-13

## 2. チケット購入（会員）

### EC-07 チケットを購入する
【会員のファン】として、【公式サイトでチケットを購入】したい、なぜなら【いろんなサイトよりまとまっていた方が買いやすい】から。

**受け入れ条件**
- 出演スケジュール詳細から、チケット購入に進める
- 未ログインの場合は、ログイン画面に案内される
- 残り枚数が0の公演は購入できない

**関連**：US-08 / F-14

### EC-08 枚数を選ぶ
【会員のファン】として、【購入するチケットの枚数を選択】したい、なぜなら【友達と一緒にライブに行きたい】から。

**受け入れ条件**
- 1枚または2枚を選択できる
- 同じ公演のチケットは、1人で合計2枚までしか購入できない（すでに1枚買っていれば、あと1枚まで）
- 選んだ枚数に応じた合計金額が表示される

**関連**：US-08 / F-14

### EC-09 電子チケットを確認する
【会員のファン】として、【購入したチケットをマイページで確認】したい、なぜなら【ライブ当日に、すぐにチケットを提示したい】から。

**受け入れ条件**
- 購入完了後、登録メールアドレスに完了メールが届く
- マイページに電子チケット（購入番号・公演日時・会場・枚数）が表示される
- 他の会員のチケットは見られない

**関連**：US-08 / F-14

### EC-10 購入履歴を確認する
【会員のファン】として、【自分の購入履歴を確認】したい、なぜなら【いつ何を買ったのかを把握しておきたい】から。

**受け入れ条件**
- 購入したチケット・グッズが、新しい順に一覧で表示される
- 購入日・商品名・数量・金額が表示される

**関連**：US-12 / F-15

## 3. 商品・注文の管理（管理者）

### EC-11 商品を登録・管理する
【管理者】として、【グッズ・チケットの商品情報と在庫を管理】したい、なぜなら【売り切れや価格変更をすぐに反映し、ファンに誤った情報を見せたくない】から。

**受け入れ条件**
- グッズの登録・編集・削除ができる（画像・商品名・価格・説明・在庫数）
- チケットの販売枚数・価格を、出演スケジュールごとに設定できる
- 管理者以外はこの画面にアクセスできない

**関連**：US-17 / F-23

### EC-12 注文を確認する
【管理者】として、【チケット・グッズの注文を一覧で確認】したい、なぜなら【グッズの発送やチケットの販売状況を把握したい】から。

**受け入れ条件**
- 注文が新しい順に一覧で表示される
- 注文番号・購入者名・商品名・数量・金額・購入日時が表示される
- グッズの注文では配送先が確認できる

**関連**：US-21 / F-28
